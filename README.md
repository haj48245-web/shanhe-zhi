# 山河志 · 中国人文旅行图鉴

一张可以点开的中国人文旅行地图。点击省级行政区，先读全省概况，再进入城市，看古建、山水、博物馆、非遗、民俗、风物、名人与“中国/世界之最”，并把每一样东西背后的文化脉络讲清楚。

## 打开方式

**最简单：双击 `index.html`。**

数据与图片都使用相对路径，直接以 `file://` 打开即可，不需要安装任何依赖，也不需要联网。

如果浏览器对本地脚本有限制，可以在本目录运行一个本地静态服务器：

```powershell
python -m http.server 8765
```

然后访问 <http://127.0.0.1:8765/>。

Windows 用户也可以双击 `打开山河志.bat`。

## 内容规模

- **34 个省级行政区**：省 / 自治区 / 直辖市 / 特别行政区。
- **384 座城市与地区**：覆盖全部地级行政区，直辖市与港澳台按城区/区域拆分。
- **1,007 个文化坐标**：古建、遗址、山水、文博、非遗、民俗、风物、名人、之最。
- **8 篇跨省文化专题**：元曲四大家、汝官哥钧定与景德镇、五岳、长江水系、江南园林、中国古建、大运河、六大茶类。

内容分两个层次：

- **深度城市**（北京、天津、河北、山西）：每城 3–6 个条目，文化深读 180–320 字。
- **城市速览**（其余地区）：每城 2–3 个条目，保留最值得记住的地标、文化坐标与地方风物，适合先建立整体认知。

## 功能

- **可点击的中国地图**：省级行政区按地理区域着色，悬停显示省份气质与城市数量，支持键盘操作。
- **省份总览**：地理格局、历史脉络、文化性格、代表物产、最佳季节、建议线路。
- **城市索引条**：进入省份后，顶部直接列出所有城市，点一下就能切换。
- **城市详情**：城市名片、吃什么、怎么走、按类别筛选的文化坐标。
- **文化深读**：每个条目可展开，讲朝代、人物、制度、流派、工艺、典故与地理关系。
- **全站搜索**：搜城市、古建、山水、非遗、称号；支持 `⌘K` / `Ctrl K`、`/` 快捷键。
- **文化专题**：跨省横向阅读，把分散在各地的东西放回同一条文明脉络。
- **响应式**：桌面为“地图 + 详情”双栏；手机进入省份后自动切换为全屏详情，点右下角“地图”返回。
- **离线可用**：图片已本地化为 WebP；缺失图片会自动回退为带城市首字的纸感色块。

## 数据与图片说明

- 文字为编辑整理与科普写作，参考公开史志、博物馆、世界遗产与地方文旅资料；称号、年代与遗产信息会随官方更新而变化，出行前请以当地文旅部门与景区公告为准。
- 图片通过公开图片检索获取，已下载并转为本地 WebP，仅作学习与展示，版权归原作者所有；来源记录见 `data/images/credits.json`。如需商用，请自行核实授权。
- 地图边界数据来自公开的中国省级行政区 GeoJSON（ECharts 地图数据），经简化后用于交互展示，不作测绘用途。

## 重新生成

```powershell
# 1. 生成省份任务
python tools/make_tasks.py
python tools/make_compact_tasks.py

# 2. 合并原始内容，生成 assets/data、搜索索引与 manifest
python tools/build_data.py

# 3. 生成图片任务并检索、裁剪、本地化
python tools/make_image_tasks.py
python tools/fetch_images.py

# 4. 重新生成简化地图
python tools/build_map.py
```

`build_data.py` 会输出 `data/build-report.json`，列出缺条目、缺简介、JSON 解析失败等需要人工复核的项。
